# 🌱 EcoTracker

EcoTracker is a full-stack web application for monitoring and analyzing environmental data related to coal-mining operations. It allows users to record metrics such as energy consumption, fuel usage, coal production, and transportation distance, and provides analytics and emission-reduction recommendations through an interactive web interface.

##  Features

* Collect and store coal-mine operational and emission data
* Visualize collected data using interactive charts
* Analyze recent emission metrics
* Calculate required emission reductions
* Suggest possible emission-reduction strategies
* User signup and login

##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Chart.js
* **Backend:** Node.js, Express.js
* **Database:** MySQL

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Shivasai-15/EcoTracker.git
cd EcoTracker
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure MySQL

Create the required MySQL database and tables, then update the database connection details in the project files.

### 4. Start the server

```bash
node app.js
```

### 5. Open the application

Go to:

```text
http://localhost:3000
```
